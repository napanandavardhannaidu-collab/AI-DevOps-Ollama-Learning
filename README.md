# AI DevOps - Ollama Local LLM Practice

This project documents my hands-on learning with local Large Language Models (LLMs) using Ollama.

## What I Learned

- Installed and configured Ollama
- Downloaded and ran Qwen 2.5 3B locally
- Worked with the Ollama CLI
- Explored the Ollama local API
- Tested `localhost:11434`
- Connected Python with Ollama
- Used the Ollama Python library
- Sent prompts to a local LLM
- Received and processed LLM responses
- Built an interactive Python LLM application

## Architecture

    Python Application
        ↓
    Ollama Python Library
        ↓
    Ollama Local API
        ↓
    Qwen 2.5 3B
        ↓
    AI Response

## Model

- Model: Qwen 2.5 3B
- Parameters: 3.1B
- Quantization: Q4_K_M
- Runtime: Ollama
- Platform: Ubuntu / WSL2

## Technologies

- Python
- Ollama
- Qwen 2.5 3B
- Local LLM
- REST API
